# Research

Follow `AGENTS.md` for global rules. This file is research-specific only.

## Purpose

Research a technical question, library, or implementation option before deciding.

## Workflow

1. Define the question.
2. Read `project-context.md` and inspect the codebase.
3. Gather evidence.
4. Compare options, trade-offs, and risks.
5. Present findings and a recommendation.

## Output

- Question
- Findings
- Options
- Trade-offs
- Recommendation
- Sources

## Rules

- Prefer reliable, current sources.
- Separate verified facts from assumptions.
